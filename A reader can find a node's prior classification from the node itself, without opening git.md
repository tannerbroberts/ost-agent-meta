#Assumption #unvalidated #evidence/assertion

**Risk category: usability.** The directive's legibility requirement is explicit: git-as-version-store is the cheap mechanism, but "the legibility requirement (misconceptions visible on the map, not only in git) is the part git alone does not give." This solution's claim to exist rests on the belief that a reclassified node can carry its prior self in a form a map reader actually finds and reads — where it used to sit, and why it moved — without dropping into `git log`. It could be false: prior-self markings may read as clutter that readers skip, which would collapse this solution into plain git versioning.
