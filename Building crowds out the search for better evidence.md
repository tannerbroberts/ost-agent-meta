[[Split the cartographer loop from the builder loop]]

**The need (customer's voice):** "Whenever there is code to write, everything else stops. Nobody is asking whether we are building the right thing — the asking loses to the building every single time, and I only notice months later."

**Why it matters:** Hunger for evidence and the urge to ship compete for the same attention. If one agent (or one person) holds both jobs, delivery wins by default, the map stops improving, and the product drifts toward whatever was most recently mentioned rather than toward the highest-signal need.

**Litmus test:** More than one way to address it — separate loops with separate mandates, a protected discovery budget, a gate that refuses to build against an unvalidated assumption, an evidence-debt metric that rises when only building happens. Passes.

**Reframing note:** The source input was solution-shaped ("separate an IDEATION loop from a BUILDER loop"). It has been reframed upward into the underlying need. The specific two-loop split now belongs one layer down as a candidate solution, and is recorded there. A human should confirm the reframing is faithful.
