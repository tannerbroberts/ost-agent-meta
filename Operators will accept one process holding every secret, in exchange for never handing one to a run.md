#Assumption #unvalidated #evidence/assertion
[[Ask five operators whether they would put their secret in a broker that acts for a run]]

The broker's whole advantage is that the run never possesses the credential. Its cost is concentration: every secret the operator has, in one process on one machine. This solution is only worth building if operators will make that trade — and the node itself says that for some of them it is plainly unacceptable.
