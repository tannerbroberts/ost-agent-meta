#AssumptionTest #unvalidated #evidence/assertion

The assumption is that a useful number of open assumptions carry questions public information could answer. If almost all of them turn on this product's own customers and this product's own behaviour, demand-pulled lookups will have nearly nothing to spend on and the mechanism is idle machinery.

**Risk category: feasibility.**

**Design.** Walk every open assumption test in the vault. For each, ask whether any publicly available source could shift belief about it, and if so write the question that would be searched. Count the ones that produce a real question.

**Why it is small.** A read of the tree, no lookups spent, and the questions produced are directly usable if the answer is favourable.

**What it will not cover.** Judging that a public source could help is not the same as one existing. A question that looks answerable may return nothing, and this counts the first thing rather than the second.
