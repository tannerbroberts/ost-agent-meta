# Founder theory: theory-space proof is reality too, and the agent has no method for axioms (2026-08-10)

Spoken in session by the founder. Evidence class: **assertion** — founder theory,
recorded verbatim in substance for later distillation. No evidentiary weight until
laddered.

**The frustration that produced it.** There is a failure mode where OST-Agent does not
produce actionable opportunities and solutions. The founder locates the cause in the
evidence regime: "what it does have is rigorous, *if you happen to be able to supply
the type of evidence it's going to respect*."

**The claim.** A significant amount of work can be done in theory space that lets
reality prove things to the agent just as well as customer usage would. Mathematics
proves all sorts of things using rules that have been built up — exploring realities
that are provably true *should the axioms hold*. The load-bearing human act is the
"really very felt-out distinction between what they consider to be an acceptable
axiom and what they don't." It takes all kinds to run the world — different people
accept different axioms — but OST-Agent has no method of determining axioms at all.

**Session-context observations recorded alongside (agent's, same rung):**

1. The believability ladder (money / observed / stated / expert / assertion) is a
   ladder of *witness* classes. A machine-checked derivation from declared axioms fits
   no rung: it is not testimony at all, and today it could only enter as `assertion` —
   the same rung as a guess — which is exactly the founder's complaint.
2. The 2026-07-24 cost-curve note already recorded the bifurcation this extends:
   machine-readable feedback is compute-purchasable grounding, human-resident feedback
   floors at reality-contact. This claim adds a third territory — *derivable* truth —
   and says the tree is blind to it.
3. The felt-out axiom distinction is a candidate for what the tree's `#Unknown`
   contract calls Format/Methodology: an axiom register would need to say what
   accepting an axiom commits the tree to, and who may accept one.

**For a future pass:** distill — candidate opportunity is roughly "proof-shaped
evidence has no rung, so theory work cannot move any node." Check against the
evidence-ladder machinery before creating structure; a proof lane and an axiom
register are the obvious solution directions, and the mapped goal-acquisition branch
already cites this note for one of them.
