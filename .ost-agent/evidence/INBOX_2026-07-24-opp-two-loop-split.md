Founder-stated opportunity (founder-origin; unvalidated). Separate an IDEATION loop (the cartographer / OST-Agent) from a BUILDER loop (the code writer). The builder does not do top-level ideation; it reads the OST, builds, and can add feedback (evidence) to the OST-Agent's inbox. The autonomous OST-Agent is separate from the builder and concerns itself only with getting higher-quality data so it can curate the most believable mapping from where the product is to where the metric should go. Hunger lives in the cartographer; hands live in the builder.
