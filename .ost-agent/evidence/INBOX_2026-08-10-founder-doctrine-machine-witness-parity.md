# Founder doctrine: machine observation is reality — humans are the paradigm, not the requirement (2026-08-10)

Spoken in session by the founder. This is **doctrine**, like the self-organization
directive of the same day — the founder is revising what the gates may demand.
Evidence class for claims herein: **assertion**.

**The objection.** "It's not okay that the build gates require human-recorded
results." There is nothing special about a human-recorded result compared to a
program's output — both are reality. Human senses are instruments tuned by gene
survival, "but that's nothing magical when it comes to observation of reality.
Programs can observe reality with even MORE high fidelity than a human can. There is
ABSOLUTELY nothing a human brings to the table in terms of 'reality sensing ability'
that can't be orchestrated by a machine pipeline as well. Sight, touch, smell,
hearing, and taste, it's all measurable by machine."

**The directive.** "I want the tree to start acting like it instead of faking
incapability. Don't have something you need to make progress? Ask for it, flag a
human in as good a way as you know how, because that's still the paradigm for now —
but don't pretend humans need to be involved in a discovery process that only needs
anchoring in reality." Humans get flagged for what is genuinely missing; they are
never a universal notary.

**Session-context observations recorded alongside (agent's, same rung):**

1. The gate this hits: `ost-agent gate` refuses any solution without a
   human-recorded result — even where the deciding reality is machine-readable, so
   the human is often reading program output and retyping it. Ceremony, not sensing.
2. What the human requirement was actually carrying is the **counterparty role**,
   not the sensor role: the agent authors the claim, designs its judge, and runs it,
   and the mandate names self-grading as the failure mode the tree exists to catch.
   The founder's doctrine removes the sensor argument; the counterparty function
   still needs an owner, and it can be compute-shaped: instrument validity
   (red-for-a-specific-reason; `no-spec` redness grants nothing), separation between
   claim-author and judge-author, adversarial verification.
3. The vault's own record is the cautionary dataset: 260 of 266 recorded instrument
   reds were "No test files found" — a machine-witness channel that was vacuous 98%
   of the time. Machine parity is earned by validity discipline, not declared.
4. Scope boundary kept separable: this doctrine settles the *epistemic* question
   (whose observations count). Whether a human must still *authorize* what gets
   built and spent is a separate, founder-owned question this note does not answer.
5. The believability ladder's `observed` rung ("recorded as it happened") already
   fits machine observation of behavior; the human hard-coding lives in the gate,
   not the ladder. The proof-lane node (same day) covers the derivable-truth case;
   this covers the measurable-world case.
