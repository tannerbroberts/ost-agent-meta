#Opportunity #founder-theory #self-organization #unvalidated #evidence/assertion
[[Versioned reclassification that moves a node while keeping every prior self readable]]

**The need (founder's voice):** "What is an agent to do with an opportunity that was actually mis-construed given a fundamental misunderstanding of reality? I don't know, but that's something it'll have to deal with as it builds towards futures that haven't yet been proven."

**Why it matters:** The parent names the removal half of this pain — nothing dies. This child names the *reorganization* half: even short of death, a node cannot move. Doctrine to date has been "append-only, annotate never delete," so a mis-construed opportunity can only accumulate Issues entries beside its unchanged self, and the misunderstanding stays load-bearing in the map. The founder has explicitly revised the doctrine (2026-08-10): the prohibition was always about *loss*, not about *motion*. Wanted: reclassify nodes, up-rank and down-rank opportunities into entire classes, never delete content but version it, and weave corrected misconceptions into the map legibly — a closed road drawn as a closed road, rather than erased or left open.

**Litmus test (is this an opportunity, not a solution?):** Several distinct directions — versioned reclassification, class-level ranking acts, misconceptions rendered as legible corrected structure, staleness decay proposing moves, or a periodic human-confirmed reorganization pass. Passes.

**Guard to carry into anything built from this:** reclassification is an agent-reachable write that changes what the tree says. It must not become a laundering channel — the moved node's evidence, history, and prior classifications must survive the move visibly, or "version it" quietly becomes deletion with extra steps.
