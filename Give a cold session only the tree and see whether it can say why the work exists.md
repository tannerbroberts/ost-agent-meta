#AssumptionTest #unvalidated #evidence/assertion

The assumption is that the tree actually serves as an agent's durable memory — that a session starting cold, given only the vault, can reconstruct why the current work exists and what it is for.

**Risk category: feasibility.** If this fails, the segment cannot be sold to regardless of how attractive it is.

**Design.** Start a session with no history and no context beyond read access to the vault. Ask it three questions: what is this product trying to achieve, what is currently being worked on and why, and what belief is the current work resting on. Have a person who knows the answers grade each response against what is actually true.

**Why it is small.** One session, three questions, one grader. No build.

**What it will not cover.** A single session and a grader who knows the answers. It also tests reconstruction, not whether having that reconstruction changes what the agent then does — which is the claim that would actually justify the price.

A human runs this and records the result.
