#AssumptionTest #unvalidated #evidence/assertion

**Lane: humans-required.** Take an actual pass's dismissals, with reasons, and put them in front of five operators who run unattended agents. Ask each whether they would have let the list stand unreviewed, and — separately, because the answers may differ — whether they would still say so after finding one dismissal they disagreed with.

This is the test that should run before either of the cheap siblings is built, not after. If operators will not accept dismissal-by-assertion, "A disposition record every bucket consults before it lists anything" is dead regardless of how cleanly it can be implemented, and the two derivation-based candidates are the only acceptable answers because they cannot be talked into anything. Building the ledger first and asking afterwards is the expensive order.

The five must be operators, not the founder. This tree's own mandate says no node may climb the believability ladder on founder or model sources alone, and this assumption is exactly the kind that would feel obviously true from inside the building.

A person outside the building is the measurement here: A person outside the building is irreducibly the measurement: the question is whether an operator would trust an agent that dismisses its own work list, and no exit code can report on someone's willingness to walk away. Show them a real dismissed-work list from a real pass and ask.
