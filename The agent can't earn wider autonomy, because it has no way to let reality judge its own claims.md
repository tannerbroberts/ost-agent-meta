#Opportunity #founder-theory #needs-customer-interview #goal-acquisition #unvalidated #evidence/assertion
[[Unattended feasibility tests the agent runs against its own environment]]
[[A proof lane where derivations from declared axioms count as evidence]]
[[An autonomy ledger that widens permission as staked claims survive their instruments]]
[[There's no way to declare which axioms I accept, so derivable truth can't move the tree]]

**The need (founder's voice):** "This repo wants to grow its autonomy as it proves to itself with reality that it deserves it. To make progress on something, an agent needs proper autonomy to not only make a guess as to how the world works, but also test that guess, stake a claim on untested ground, and see if it sticks."

**Why it matters:** The parent umbrella is trust-to-walk-away, and every facet beneath it so far earns trust by *constraining* the agent — allowlists, stamps, gates. This facet is the missing complement: a channel by which the agent can *expand* what it is trusted with, by staking claims and letting reality grade them. Today the product has steps (1) and (3) of the founder's four structurally — everything agent-made enters `#unvalidated`, an honest stake — and lacks (2) and (4) by design: DEC-3 ("an agent that answers feasibility questions by executing tests against its environment unattended") is recorded as deliberately unbuilt in `docs/reference/v1-readiness.md`, and validation of agent ideas is human-only. The founder's frustration names the consequence: the rigor only works "if you happen to be able to supply the type of evidence it's going to respect" — so where no customer is available to witness, nothing can be proven, and opportunities stop being actionable.

**Litmus test (is this an opportunity, not a solution?):** Several distinct directions — unattended feasibility testing against the environment (shipping DEC-3), a proof lane where derivation from declared axioms counts as evidence, an autonomy ledger that widens permission on instrument track record, agent-staked sub-goals carrying their own judges. Passes.

**Boundary, stated so the exciting reading cannot swallow the buildable one:** this is goal acquisition *beneath* the mandate. "An agent must never originate the mandate it steers by" (`src/mcp/setup.ts`) is untouched; relaxing it would be a mandate change and is the founder's alone. What this node claims is that between the fixed root and the evidence the tree respects, there is a whole territory of claims the agent could be staking and testing itself.
