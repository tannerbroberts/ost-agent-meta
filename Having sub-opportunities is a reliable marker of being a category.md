#Assumption #unvalidated #evidence/assertion
[[The category exemption does not silence a childless gap]]

**Kind: feasibility.**

**The belief, stated so it could be false.** The exemption reads one edge and concludes "category". But an ordinary leaf need can acquire a single sub-opportunity — the tree does this routinely, by splitting a need into a sharper child — and the moment it does, this rule stops asking it for solutions forever, even if neither the parent nor the child has any.

"The same refusal is rediscovered every session, because nothing carries the lesson forward" is exactly that shape today: it became a parent when its three solutions were re-parented onto a child, and it now reads as under-served for a reason that is not a gap. This rule would silence it correctly. The question is how many nodes it would silence *incorrectly*.

**What would make it false.** A node with one or more Opportunity children where neither it nor any descendant carries a solution — silenced by this rule and genuinely a gap.
