#Assumption #machine-witness #goal-acquisition #unvalidated #evidence/assertion
[[Ask the founder whether a machine-cleared permit may start a build with nobody watching]]

**Risk category: viability (authorization).**

The belief, stated so it can be wrong: once the gate accepts machine-witnessed verdicts, a cleared permit is actually allowed to start build work unattended — the founder does not still require per-instance sign-off before effort is spent.

The doctrine this solution rests on explicitly did not answer this: it settled the epistemic question (whose observations count) and left "whether a human must still authorize what gets built and spent" as a separate, founder-owned question. If the founder's answer is "authorization stays per-instance", the gate change still removes retyping ceremony but the queue-behind-a-human this solution promises to dissolve remains fully intact — the solution's headline value collapses to a bookkeeping improvement.

This is distinct from the neighbouring autonomy-ledger question of which permission classes a survived stake may *widen*: that is about scope growth over time; this is about whether the very first machine-cleared permit may act at all without a signature. No repository spec can answer it; the founder is irreducibly the measurement.
