#Assumption #unvalidated #evidence/assertion
[[Would an operator accept the agent living inside the vault it maintains]]

Upgrading by git pull is only simple if committing the agent into a repository the operator keeps is acceptable to them. If it is not — and for a repository they treat as their record, it may well not be — the mechanism is elegant and unusable.
