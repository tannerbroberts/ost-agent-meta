**The need (founder's voice, 2026-08-10):** Significant work can be done in theory space — derivations that are provably true *should the axioms hold* — but "OST-Agent has no method of determining axioms at all." The load-bearing human act is the "really very felt-out distinction between what they consider to be an acceptable axiom and what they don't." Without a way to declare accepted axioms, no derivation has anything agreed to stand on, so theory work cannot move any node — the tree only respects witness-class evidence (money / observed / stated / expert / assertion), and a machine-checked derivation fits no rung.

**How this differs from the sibling solution.** "A proof lane where derivations from declared axioms count as evidence" (hanging beside this node) is one way to *consume* declared axioms. This node holds the upstream need: the declaring itself — who may accept an axiom, what accepting one commits the tree to, and how an axiom is later revised or revoked. A proof lane with no axiom register consumes nothing.

**Litmus test (more than one way to address?):** Yes — an axiom register file the human edits; axioms as first-class vault nodes with their own history; per-derivation acceptance prompts at review time; axioms inherited from committed configuration. Passes.
