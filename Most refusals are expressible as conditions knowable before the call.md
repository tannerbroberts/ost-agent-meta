[[Try to express every refusal this tool can issue as a precondition, and count the ones that resist]]

Published preconditions are a second copy of the rules, and a second copy drifts. A caller checking against a stale description is confidently wrong, which is worse than being told no — so the coverage has to be high enough to justify carrying the copy at all.
