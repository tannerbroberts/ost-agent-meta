#AssumptionTest #unvalidated #evidence/assertion

**Small, fast test of one belief.** Stage a 20-minute triage session over this tree's actual category buckets. The only verbs offered are up-rank class / down-rank class (paper or mock UI — nothing need be built). A facilitator records each act and each moment the founder asks to break a class apart or touch a single node instead.

**Pass:** the founder completes the triage using class-level acts on at least two classes and confirms on readback that the outcome matches their intent. **Fail:** they abandon class verbs for per-node judgements on most decisions, or the classes the tree can draw are not the ones they reach for — either way bulk-rank is the wrong verb and this solution should not be built as designed.

**What this does not settle.** One founder, one session: nothing about other operators, and nothing about the mechanism for recording a class rank durably.

A person outside the building is the measurement here: The founder is irreducibly the measurement: how they triage under load is behavior only a staged session with them can observe.
