#Assumption #unvalidated #evidence/assertion
[[Match one candidate pattern against the stored corpus and count what it covers and what it would hide]]

**The belief, stated so it can be false.** There is a pattern an operator would actually be willing to write — specific enough that they can predict what it hides — which still covers a large share of the 85 transcript records. If it exists, one dismissal replaces eighty-five and the operator keeps a defensible sentence about what they hid.

It is false if the corpus does not cluster that cleanly. The records vary: some carry a permission denial, some an `InputValidationError`, some only retries, and the counts differ. If the only pattern covering most of them is broad enough to also cover a future record that matters, then the safe pattern covers a third of the queue, the operator writes four patterns instead of one, and the saving is not worth a schema change.

**Category:** feasibility — a fact about the shape of the corpus that already exists on disk.

**Why this is the riskiest belief here.** The solution's whole value is the ratio between one act and eighty-five. Whether operators *want* a standing dismissal is a real desirability question and a separate one; if the coverage is not there, that question never needs asking.
