#AssumptionTest #unvalidated #evidence/assertion

The assumption is that the comparison can be made credible. The operator running both arms built one of them, and there is no version of this where that bias is absent — so the result will be worth roughly what an outside reader thinks the bias is worth.

**Risk category: viability.** Whether the exercise can produce evidence anyone outside will accept.

**Design.** Before running two weeks of anything, recruit one person who did not build this tool and is willing to maintain the hand-built arm. Give both arms the same corpus and the same time. If nobody can be recruited, that answers the question about the comparison's credibility at a cost of a few conversations rather than a fortnight.

**Why it is small.** Recruiting is days, and it gates the expensive part. Running the full comparison with the author on both arms produces something that cannot be published convincingly.

**What it will not cover. **One outside participant does not make the comparison neutral — the corpus, the measures, and the framing are all still the author's.

A human runs this and records the result.
