#Solution #founder-theory #goal-acquisition #unvalidated #evidence/assertion

Ship the mechanism DEC-3 already describes and `docs/reference/v1-readiness.md` records as deliberately unbuilt: when the tree holds a feasibility question — can this resource be acquired, does this path exist, does this command work here — the agent designs the probe, executes it against its working environment unattended, and records the observation. This is steps (2) and (4) of the founder's four: test the guess, see if it sticks. The witness is the environment itself, so no human testimony is displaced; what a human loses is only the veto over *running* the probe, never over interpreting a claim about people.

**Contrast with siblings:** the proof lane wins truth by derivation without touching the world; the autonomy ledger changes what the agent is *allowed* to do; this one changes what the agent can *know* — it is the direct empirical limb, and the precedent already half-exists in the build loop's red-before-green instrument runs.
