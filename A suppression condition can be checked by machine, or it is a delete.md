#Assumption #unvalidated #evidence/assertion

Feasibility, and it is the whole solution. Suppression is safe only if the reviving condition is evaluable without judgement — "this solution's status is no longer shipped", "this test has acquired a lane label". A condition stated in prose is a promise nobody can check, and an item suppressed on one is removed from the queue permanently by an agent's own say-so. If the conditions worth expressing turn out not to be machine-checkable, this solution collapses into the delete tool the surface deliberately withholds.
