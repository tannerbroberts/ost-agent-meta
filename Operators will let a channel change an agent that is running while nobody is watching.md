#Assumption #unvalidated #evidence/assertion
[[Would operators enable an update channel that can change an unattended agent]]

The mechanism requires consent to unattended change. Told plainly what the channel can do, an operator may decide that an agent which can be altered mid-run is exactly the thing they were not willing to leave alone — which would make the channel unshippable rather than merely unpopular.
