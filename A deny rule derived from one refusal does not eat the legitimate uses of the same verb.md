[[Check a derived deny rule against legitimate uses of the same verb it was derived from]]

`sleep` before a poll is wrong; `sleep` in a fixture that needs a real delay is not, and a rule derived from the first will eat the second. Narrowing the environment is only safe if the inferred class matches the class that was actually wrong — and every derived rule stays reversible by a human.
