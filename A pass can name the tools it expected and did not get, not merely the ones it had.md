[[The run record names the tools it had and the ones it expected and did not get]]

Recording what was present is easy; recording what was absent requires the pass to know what it expected. Without the expectation half, a degraded record and a complete one differ only by a shorter list, which is exactly the ambiguity this exists to remove.
